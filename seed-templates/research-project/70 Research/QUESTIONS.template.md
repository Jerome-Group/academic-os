# Questions

Mathematical unknowns worth returning to. A question leaves this list only when the Owner can
state what settled it or chooses to park it with a reason.

Copy this interface for a real Question; the fenced copy is not an entry:

```markdown
## question-key — Short question

- Status: open
- Question and scope:
- Current evidence:
- Settled by or reason parked:
```

Statuses: `open`, `parked`, `settled`.
