## Findings and measurements

The audit reproduced and fixed unknown-command audit fallback, duplicate/unchecked CLI flags,
unproved cheatsheet coverage destinations, hardcoded native leading, public morning-report free
text, cycling/malformed provider tokens, missing early-launcher receipts, academic-mount log alias
escape and inaccurate MCP mirror-write metadata. Each has a public-seam fixture regression.
Independent review also reproduced a review-package directory-swap race. Publication now retains
an exclusively claimed destination and uses the seed publisher's additive exclusive writes;
replacement identities and concurrent file bytes survive refusal. Partial publication remains
available for reconciliation. Ordinary pathname APIs do not provide an adversarial atomicity guarantee.

A bounded old Tasks-pagination fixture required forced stop after four requests. The corrected
cycling walk refuses after two requests; malformed tokens refuse after one. Register/mirror state
survives refusal and a subsequent healthy retry. There is no arbitrary ceiling on legitimate pages.

The isolated baseline complete check passed in 32.47 seconds. It already ran all tests through
rule coverage; describing it as omitting tests would have been wrong. The improved complete profile
retains that single shared test/privacy/coverage run and adds template compilation plus the full
synthetic release journey. Its structured result records individual timings rather than claiming
unlike workloads establish a speedup.

`npm audit` reported zero known advisories on this date. Registry inspection found newer Biome,
Node types, esbuild, google-auth-library and yaml releases. No evidenced compatibility/security
need justified bundling speculative upgrades; their newer versions remain untested. Clean installs
also report the existing node-domexception deprecation and esbuild install-script approval notice.
No global npm approval policy changed.
