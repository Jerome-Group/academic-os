# Weekly resolution reuses publication ownership

Status: accepted. Issue: #380.

ADR-0038 retains its immutable reviews, Owner text preservation, transfer semantics, and one private
journal owner. It leaves the current quiet anchor open. This decision adds current-anchor resolution
under that same owner because an external closer would compete with publication and reopening.

A resolution requires a fresh complete monitoring-cohort observation, explicit repository evidence,
and a conservative combined view without actionable work. A module-only pass or missing repository
input cannot establish that result. Retained pending repository identities still require matching
verification and rollout evidence. A later green baseline does not erase them.

The morning CLI refuses any unresolved configured cohort selection before state creation or routine
effects, including Module-only recovery. Its error names each unresolved semester, Module, and reason
so omitted ambiguous targets cannot become complete coverage. An explicitly empty active Module list
remains supported by the configuration contract. It contributes zero Module targets, while full
resolution still requires successful prelude and repository evidence. Empty selection caused by
unresolved mappings always refuses.

An open anchor receives a new immutable resolution review even when its ordinary status is unchanged.
The close intent binds its exact numeric anchor, publication, observation ticket, observed identities,
unknown predecessors, and reduced-view digest. The writer rereads those facts immediately before a
state-only close and requires exact CLOSED readback and a durable receipt before reporting closure.
Admission reserves the entire planned publication and state evidence before its first remote effect.

Resolution concerns observed machine evidence. Owner notes remain untouched and are not implicitly
resolved. GitHub enumeration provides no snapshot isolation. Facts arriving after the final scan can
require a later reopen. Closed anchors remain observable, and new actionable evidence reopens through
the same owner. A quiet unchanged closed anchor produces no duplicate review or close.

Lost responses retain their intent. Exact trusted readback can acknowledge a committed close without
repeating the write. The current evidence reducer still decides whether to reopen. Legacy journal
state operations keep their original parsing and semantic digests. Neither a predecessor transfer
close nor an old state receipt becomes resolution proof.

This adds no general repair backlog, retry scheduler, or notification transport. Repository repair
and its delivery gates remain separate. Notification delivery needs its own supported adapter and
acknowledgement before it can be claimed.
